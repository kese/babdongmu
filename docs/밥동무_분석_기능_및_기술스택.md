# 밥동무 앱 분석 — 기능 및 기술 스택

작성일: 2025-11-10

## 한줄 요약
- 앱 타이틀: 밥동무
- 플랫폼/프레임워크: Flutter (Dart) 기반 모바일 앱
- 목적: 함께 배달하거나 같이 먹을 사람을 모으고, 게시글 작성/참여와 채팅을 통해 소통하는 커뮤니티형 매칭 앱

## 사용된 언어 및 기술 스택
- Dart / Flutter (주요 UI 및 비즈니스 로직)
  - 근거: `pubspec.yaml`, `lib/main.dart`, `lib/pages/*`, `lib/services/*` 등
  - Flutter 패키지: `http`, `shared_preferences`, `image_picker`, `intl`, `cupertino_icons`

- 로컬 저장: `shared_preferences`
- 이미지 선택: `image_picker`

## 주요 기능 (구현 위치 및 세부 동작)

1) 인증
- 로그인: `lib/pages/login.dart`, `lib/services/auth_api.dart`, `lib/services/api.dart`
  - 동작: `AuthApi.login()` 호출 → 성공 시 `ApiService.saveToken()` 및 `saveUserInfo()`
  - 공유 계정이나 고정 로그인 정보는 제공하지 않음
- 회원가입: `lib/pages/signup.dart`, `lib/services/auth_api.dart`
  - 폼: 이메일, 비밀번호(+확인), 이름, 닉네임, 주소, 전화번호, 계좌번호, 프로필 이미지(업로드 로직 TODO)

2) 홈 / 게시글 (탭 기반)
- 메인 구조: `lib/main.dart`, `lib/pages/home.dart`
- 게시글 작성: `lib/pages/create_post.dart`, `lib/widgets/delivery_form.dart`, `lib/widgets/friend_form.dart`
  - 유형: 배달(PostType.delivery), 식사친구(PostType.friend)
  - API: `PostApi.createDeliveryPost()`, `PostApi.createFriendPost()` (dev-mode 포함)
- 게시글 목록/참여: `lib/widgets/delivery_tab.dart`, `lib/widgets/friend_tab.dart`, `lib/services/post_api.dart`
  - 참여 처리: `PostApi.joinDeliveryPost()` / `joinFriendPost()` — dev-mode에서 인원 증가와 채팅방 생성 시뮬레이션

3) 채팅
- 채팅방 목록: `lib/pages/chat_list_page.dart`, `lib/services/chat_api.dart`
- 채팅 룸: `lib/pages/chat_room_page.dart`, `ChatApi.getChatMessages()`, `ChatApi.sendChatMessage()`
  - dev-mode: 더미 메시지와 즉시 성공 응답 제공

4) 로컬 상태 및 세션 관리
- 토큰, 사용자 ID, 프로필 정보는 앱 프로세스 메모리에만 보관하며 앱을 다시 열면 재로그인 필요

5) 개발 편의(모의 데이터)
- `APP_USE_MOCK_DATA=true` 빌드 정의를 전달하면 `AuthApi`, `PostApi`, `ChatApi`에서 더미 데이터 반환

## 실행 / 확인 팁
- 더미 데이터로 동작 확인 가능: `--dart-define=APP_USE_MOCK_DATA=true`
- 실행 예 (Flutter 환경):

```powershell
flutter pub get
flutter run
```

- 디버그용 공유 로그인 계정은 제거됨

프로젝트는 내부 테스트용 프로토타입으로 폐기되었으며, 대외 공개 서비스로 출시하거나 운영한 적이 없습니다. 현재 사용할 수 있는 서버는 없습니다.

## 권장 다음 단계 (우선순위)
1. 백엔드(엔드포인트 및 응답 스펙) 확보 → `ApiService`와 도메인 API들(`auth_api`, `post_api`, `chat_api`)을 실제 스펙에 맞춰 조정
2. 프로필 이미지 업로드 및 저장(서버/클라우드) 구현
3. 알림/푸시(Firebase Cloud Messaging 등) 통합
4. 통합 플로우 테스트 자동화(로그인 → 게시글 작성 → 참여 → 채팅)
