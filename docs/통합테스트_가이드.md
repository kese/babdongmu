# 통합 테스트 가이드

## 통합 테스트란?

통합 테스트는 실제 앱을 실행합니다. 기본 설정에서는 예약된 `example.invalid` 주소를 사용하므로 외부 API를 호출하지 않습니다. 원격 API 테스트는 명시적으로 활성화해야 합니다.

## 설정 완료 ✅

통합 테스트가 이미 설정되어 있습니다:
- ✅ `integration_test/` 폴더 생성
- ✅ `test_driver/` 폴더 생성  
- ✅ `pubspec.yaml`에 의존성 추가
- ✅ 기본 테스트 파일 작성

## 실행 방법

### 1. 준비사항

원격 테스트는 아래 빌드 정의를 모두 전달한 경우에만 실행됩니다.

```text
API_BASE_URL=https://격리된-테스트-서버
CHAT_WEBSOCKET_URL=wss://격리된-테스트-서버/ws/websocket
ENABLE_REMOTE_INTEGRATION_TESTS=true
INTEGRATION_TEST_PASSWORD=일회용-테스트-비밀번호
```

기존 계정 로그인 테스트에는 `INTEGRATION_TEST_EMAIL`도 필요합니다. 별도의 폐기 가능한 데이터베이스와 테스트 계정을 사용하세요.

### 2. Android 디바이스/에뮬레이터에서 실행

```bash
# 방법 1: 직접 실행
flutter test integration_test/app_test.dart

# 방법 2: flutter drive 사용 (권장)
flutter drive \
  --driver=test_driver/integration_test.dart \
  --target=integration_test/app_test.dart
```

### 3. Chrome 브라우저에서 실행 (웹)

```bash
flutter test integration_test/app_test.dart -d chrome
```

### 4. VS Code에서 실행

1. 디버깅 패널 열기 (Ctrl+Shift+D)
2. 통합 테스트 설정 추가 (필요 시)
3. 실행 버튼 클릭

| 항목 | 유닛/위젯 테스트 | 통합 테스트 |
|------|----------------|------------|
| **앱 실행** | ❌ 위젯만 테스트 | ✅ 실제 앱 전체 실행 |

## 테스트 작성 예시

### 기본 구조
```dart
import 'package:integration_test/integration_test.dart';

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();
  
  testWidgets('테스트 이름', (WidgetTester tester) async {
    // 앱 시작
    app.main();
    await tester.pumpAndSettle();
    
    // 테스트 코드
    await tester.tap(find.text('버튼'));
    await tester.pumpAndSettle();
    
    // 검증
    expect(find.text('결과'), findsOneWidget);
  });
}
```

### 주의사항

1. **대기 시간 충분히 주기**
   ```dart
   // 네트워크 호출은 시간이 걸림
   await tester.pumpAndSettle(const Duration(seconds: 5));
   ```

2. **실제 UI 요소 찾기**
   - `TextField` vs `TextFormField` 구분
   - 실제 UI 구조 확인 후 테스트 작성

3. **에러 처리**
   ```dart
   // 에러 다이얼로그가 나타날 수 있음
   final errorDialog = find.text('알림');
   if (errorDialog.evaluate().isNotEmpty) {
     await tester.tap(find.text('확인'));
     await tester.pumpAndSettle();
   }
   ```

## 문제 해결

### 서버 연결 오류
- 기본 설정에서는 서버가 없으며 `.invalid` 주소를 사용합니다.
- 원격 테스트를 실행할 때만 격리된 서버 주소와 연결을 확인하세요.

### 테스트가 너무 느림
- 네트워크 호출은 시간이 걸립니다
- `pumpAndSettle`의 대기 시간 조정

### UI 요소를 찾을 수 없음
- 실제 앱을 실행하여 UI 구조 확인
- `flutter run`으로 디버깅
